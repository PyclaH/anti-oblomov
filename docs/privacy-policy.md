# Политика конфиденциальности приложения «Анти-Обломов»

Действует с 26.10.2026. Приложение: «Анти-Обломов» (ru.shashkov.antioblomov). Автор: Руслан Шашков, школьный проект, Гимназия № 25 г. Иркутска. Связь: через [страницу проекта на GitHub](https://github.com/PyclaH/anti-oblomov/issues).

## Коротко

Все данные остаются на вашем телефоне. Приложение не имеет доступа к интернету, ничего никуда не отправляет, не показывает рекламу и не использует сторонние сервисы аналитики.

## Какие данные использует приложение и зачем

**Служба специальных возможностей (Accessibility Service).** Служба узнаёт, какое приложение сейчас открыто на экране (его системное название, например `com.google.android.youtube`). Если это приложение в вашем списке блокировки и сейчас время блокировки, поверх него показывается экран с цитатой. Android даёт службам спецвозможностей доступ к содержимому окон; «Анти-Обломов» использует только название открытого приложения — не читает текст на экране, сообщения, пароли и не сохраняет историю ваших действий. Перед включением службы приложение показывает это объяснение и просит согласия; без согласия служба не включается, и блокировка не работает.

**Доступ к статистике использования (Usage Access).** Нужен для раздела «Было / стало»: сколько минут в день вы проводили в выбранных приложениях до установки «Анти-Обломова» и после. Приложение читает суммарное время по приложениям из статистики Android и хранит итоги по дням только на телефоне.

**Список установленных приложений.** Нужен, чтобы вы могли выбрать, что блокировать. Список не сохраняется и никуда не передаётся.

**Ваши настройки** — расписание, таймер, выбранные приложения — хранятся во внутренней памяти приложения на телефоне.

## Передача данных

Данные не передаются ни автору, ни третьим лицам. Ссылка «Поддержать» открывает страницу DonationAlerts в вашем браузере; что вы делаете на этой странице, приложение не видит.

## Удаление данных

Все данные удаляются вместе с приложением. Службу и доступ к статистике можно выключить в любой момент в настройках телефона.

## Дети

Приложение предназначено, в том числе, для школьников. Оно не собирает персональные данные и ничего не передаёт, поэтому не получает данных о детях.

## Изменения

Если политика изменится, новая версия появится по этому же адресу с новой датой.
