# Шаг 6: мастер настройки телефона — чек-лист проверки

Что появилось:

- **Мастер настройки** при первом запуске: «Зачем» → служба блокировки (с честным объяснением, что она читает и чего не читает) → уведомления → батарея → автозапуск → итог. Любой шаг можно пропустить.
- Что сделано, приложение проверяет само: служба, уведомления, «батарея без ограничений». Автозапуск и «Контроль активности» Xiaomi из приложения не проверить — для них галочка «Сделано».
- Для каждой марки — свои подсказки и кнопки: Xiaomi/Redmi/Poco, Samsung, OPPO/Realme/OnePlus, Huawei, Honor, Vivo, Tecno/Infinix. Если нужный экран не открылся — открывается страница «О приложении».
- На главной — карточка **«Настройка телефона»**: что сделано (✓), что пропущено (⚠), кнопка «Настроить» / «Пройти настройку заново».

Сейчас проверяем только на Poco; другие марки — на шаге 8.

Перед проверкой: **Git → Fetch**, название ветки внизу справа → `origin/step-6-onboarding` → **Checkout**, затем **▶ Run**.

> Чтобы мастер показался «как в первый раз», настройки на телефоне сбрасывать не нужно: после обновления он откроется сам. Чтобы пройти его ещё раз — кнопка «Пройти настройку заново» на главной.

## Проверки

1. **Мастер при запуске.** После установки открывается «Шаг 1 из 6 · Настроим «Анти-Обломов»», внизу «Начать». Нижнего меню нет.
2. **Служба — уже включена.** На шаге «Служба блокировки» сразу «✓ Служба работает», кнопка внизу — «Далее».
3. **Служба — выключить и включить.** Выключить «Анти-Обломов: блокировка» в спецвозможностях, вернуться → «Служба пока не включена», кнопка «Открыть спецвозможности» ведёт в нужные настройки; внизу «Пропустить». Включить → вернуться → «✓ Служба работает», внизу «Далее».
4. **Уведомления.** Если уже разрешены — «✓ Уведомления разрешены». (Проверка выключения — по желанию: запретить в настройках → «Разрешить уведомления» и «Открыть настройки уведомлений» работают.)
5. **Батарея — стандартная.** Если ограничено: «Разрешить работу в фоне» → системное окно → «Разрешить» → вернуться → «✓ Работа в фоне разрешена». Если открылось не окно, а список — запишите, что именно.
6. **Батарея — «Контроль активности» (Xiaomi).** Кнопка «Открыть «Контроль активности»» → открывается экран «Анти-Обломова» (или страница «О приложении») → «Нет ограничений» → вернуться → галочка «Сделано».
7. **Автозапуск.** Кнопка «Открыть «Автозапуск»» → список автозапуска → включить «Анти-Обломов» → вернуться → галочка «Сделано» → внизу «Далее».
8. **Назад.** Кнопка «Назад» и системный жест «назад» листают шаги обратно.
9. **Итог.** Последний шаг — список с ✓ / ⚠. «Выбрать приложения» → мастер закрылся, открыта вкладка «Приложения». Повторный запуск приложения — мастера нет.
10. **Пропуск и главная.** «Пройти настройку заново» → пропустить автозапуск (снять галочку «Сделано», «Пропустить») → «На главную» → в «Настройка телефона» у автозапуска ⚠, текст «Без этих настроек…» и кнопка «Настроить».
11. **Карточка службы.** На главной в карточке «Служба блокировки» при выключенной службе кнопка автозапуска теперь называется «Открыть «Автозапуск»» и работает.
12. **Перезагрузка** (после того как всё ✓). Таймер на 10 мин → перезагрузить → блокировка работает, служба «работает».
13. *(Необязательно)* **Тесты:** `app/src/test/…/rules` → **Run Tests in 'rules'** → 117 зелёных тестов.
