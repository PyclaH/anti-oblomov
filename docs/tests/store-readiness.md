# Версия 1.1 для магазинов — чек-лист проверки

Что изменилось (для RuStore и Google Play):
- **Android 16 (API 36)** — Google Play с 31.08.2026 принимает только такие приложения. Внешне ничего не меняется.
- **Окно согласия перед службой блокировки** — требование Google Play: при первом нажатии «Открыть спецвозможности» (в мастере или в блоке «Система») — окно «Служба блокировки: что она видит» с кнопками «Принимаю» и «Не сейчас». «Не сейчас» — ничего не открывается. После «Принимаю» окно больше не появляется.
- **Политика конфиденциальности** — `docs/privacy-policy.md`, ссылка на неё нужна в обеих консолях.
- Версия **1.1** (код 2).

Перед проверкой: **Git → Fetch** → ветка `origin/store-readiness` → **Checkout**. Android Studio может попросить скачать **Android SDK Platform 36** — согласиться (жёлтая полоса «Install missing platform» или Tools → SDK Manager → Android 16 / API 36). Затем **▶ Run**.

Участникам эксперимента эту версию **не ставим**, пока он идёт.

## Проверки (на Poco)

1. **Сборка.** Проект собирается и запускается без ошибок.
2. **Окно согласия — «Не сейчас».** Выключить службу в спецвозможностях → Главная → «Система» → кнопка открытия спецвозможностей → окно согласия → «Не сейчас» → настройки НЕ открылись.
3. **Окно согласия — «Принимаю».** Ещё раз → «Принимаю» → открылись спецвозможности → включить службу → блокировка работает.
4. **Второй раз без окна.** Снова нажать кнопку открытия спецвозможностей → сразу настройки, без окна.
5. **Мастер.** «Пройти настройку заново» → шаг «Служба блокировки» → «Открыть спецвозможности» → сразу настройки (согласие уже дано).
6. **Кнопка «Назад».** Во время паузы при ослаблении и в окнах — «Назад» работает как раньше (на Android 16 изменилась обработка «Назад»).
7. **Всё остальное** — расписание, таймер, экран блокировки, «Было / стало» — как раньше.
