# Проверка шага 3: экран «Приложения»

**Что сделано:** вместо жёстко заданного YouTube пользователь сам выбирает, что блокировать.

- Список приложений с иконкой на рабочем столе, по алфавиту, с поиском по названию.
- Раздел **«Часто отвлекают»** сверху: известные соцсети и видео (TikTok, YouTube, VK, Telegram, RUTUBE, Дзен и др.) плюс игры, видео и соцсети по категории, которую приложение указывает о себе.
- Переключатель у каждого приложения; выбор сохраняется сразу, служба подхватывает его без перезапуска.
- **Не показываются и не блокируются** (FR-07): сам «Анти-Обломов», телефон и контакты, SMS, настройки, рабочий стол, клавиатура, экстренные вызовы, «Безопасность» Xiaomi. Определяются на конкретном телефоне, у разных марок — свои.
- Счётчик «Выбрано: N» и предупреждение, если не выбрано ничего.
- У нового пользователя по умолчанию **ничего не выбрано**.

> На Poco Руслана YouTube уже отмечен — он остался в сохранённых настройках с шага 2.

## Подготовка

1. Android Studio: **Git → Fetch** → **Git → Branches → Remote → origin/step-3-apps → Checkout**.
2. **▶ Run** на Poco. Карточка «Служба работает».

## Проверки

1. **Список.** Вкладка «Приложения»: сначала «Загружаю список…», затем список с иконками. Сверху «Часто отвлекают» — есть ли там YouTube, Telegram, игры с телефона? Чего не хватает?
2. **Важных нет в списке.** Поиском проверить, что не находятся: «Настройки», «Телефон», «Сообщения», «Безопасность», «Анти-Обломов», клавиатура.
3. **Поиск.** Ввести часть названия (например, «теле» или «you») → остаётся только подходящее; крестик очищает поиск.
4. **Выбор блокирует именно выбранное.** Отметить YouTube и Telegram → на главной в панели «Блокируется: Telegram, YouTube» → «Таймер 1 мин» → оба блокируются, остальные (браузер, камера) — нет.
5. **Снятие.** Снять YouTube → «Таймер 1 мин» → YouTube открывается, Telegram блокируется.
6. **Ничего не выбрано.** Снять всё → под поиском красное предупреждение; панель на главной: «Блокируется: ничего…»; таймер ничего не блокирует.
7. **Сохранение.** Отметить 2–3 приложения, перезагрузить телефон → на вкладке те же отметки.
8. **Скорость.** Вкладка открывается во второй раз сразу; при прокрутке нет рывков.
9. *(Необязательно)* **Тесты:** `app/src/test/…/rules` → правая кнопка по папке → **Run Tests in 'rules'** → 31 зелёный тест.
