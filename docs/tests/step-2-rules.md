# Проверка шага 2: расписание и таймер

**Что сделано:** YouTube больше не блокируется всегда. Блокировать или нет, решают правила по настройкам, сохранённым в памяти телефона:
- расписание по дням недели (интервалы, перерывы между ними);
- таймер разовой блокировки;
- список приложений (пока только YouTube — выбор будет на шаге 3).

Экранов расписания и таймера ещё нет (шаги 4–5), поэтому на главной — **временная панель проверки**: она показывает, что решают правила прямо сейчас, и ставит короткое тестовое расписание или таймер на минуту.

Экран блокировки теперь пишет, **до скольки** идёт блокировка: «YouTube на паузе до 16:52».

## Подготовка

1. Android Studio: **Git → Fetch**, затем **Git → Branches → Remote → origin/step-2-rules → Checkout**.
2. **▶ Run** на Poco. Служба должна остаться включённой — карточка «Служба работает».

## Проверки

1. **Свободное время.** Сразу после установки панель пишет «Сейчас: свободное время», YouTube открывается **без блокировки**.
2. **Таймер.** «Таймер 1 мин» → панель: «блокировка до ЧЧ:ММ (таймер)». Открыть YouTube → экран блокировки, вверху «YouTube на паузе до ЧЧ:ММ». Через минуту YouTube открывается свободно.
3. **Остановка таймера.** «Таймер 1 мин» → сразу «Стоп таймер» → YouTube открывается.
4. **Расписание.** «Расписание: со следующей минуты на 2 мин» → панель: «Следующая блокировка: ЧЧ:ММ». До этого времени YouTube открывается; в интервале — блокируется; после конца — снова открывается.
5. **Блокировка начинается, пока смотришь видео.** «Расписание: со следующей минуты на 2 мин» → сразу открыть YouTube и включить видео. В начале интервала YouTube должен **сам** закрыться и показать экран блокировки (с задержкой до секунды).
6. **Мини-плеер в свободное время** не трогается: видео в мини-плеере играет. Во время блокировки — встаёт на паузу (как на шаге 1).
7. **Сохранение после перезагрузки.** Нажать «Расписание…», перезагрузить телефон, открыть «Анти-Обломов» → строка «Расписание на сегодня» осталась прежней.
8. **Сброс.** «Сбросить расписание и таймер» → «Расписание на сегодня: нет», «Таймер: не запущен».
9. *(Необязательно)* **Тесты правил:** в Android Studio открыть `app/src/test/java/ru/shashkov/antioblomov/rules/BlockRulesTest.kt` → правая кнопка → **Run 'BlockRulesTest'** → должно быть 20 зелёных тестов.
