# Редизайн R4: Приложения и мастер настройки — чек-лист проверки

Что изменилось (функции те же):

**Приложения**
- Заголовок и справа счётчик-чип «Заблокировано: 3» (или янтарное «Ничего не выбрано»).
- Шапка с поиском закреплена — список прокручивается под ней; поле поиска тёмное, скруглённое.
- Заголовки разделов мелкими прописными: «ЗАБЛОКИРОВАННЫЕ», «ЧАСТО ОТВЛЕКАЮТ», «ВСЕ ПРИЛОЖЕНИЯ»; без линий-разделителей.
- Иконки приложений в скруглённом квадрате (и в списке статистики на главной тоже).

**Мастер настройки**
- Крупный номер шага «02 / 07» и тонкая терракотовая полоса прогресса.
- Иконка шага в скруглённом квадрате: часы, замок, колокольчик, батарея, автозапуск, столбики статистики, галочка.
- Статус шага — значок + текст (бирюзовый ✓ или янтарный ⚠); инструкции — номера в кружках; «Что делает / чего не делает служба» — карточки (объяснение про службу для RuStore видно целиком).
- Кнопки «Назад / Пропустить / Далее» — крупные, в новом стиле.

**Sponsr**: «Поблагодарить автора» открывает сразу страницу с донатом — `sponsr.ru/anti_oblomov/subscribe/#levels`.

Перед проверкой: **Git → Fetch** → ветка `origin/redesign-r4` → **Checkout** → **▶ Run**.

## Проверки

1. **Шапка «Приложений».** Заголовок «Приложения» и чип «Заблокировано: N»; снять все отметки → чип янтарный «Ничего не выбрано» и подсказка янтарным под заголовком.
2. **Поиск закреплён.** Прокрутить список — заголовок и поиск остаются на месте; поиск работает как раньше.
3. **Разделы и строки.** Заголовки разделов мелкими прописными, без линий; иконки в скруглённых квадратах; переключатель терракотовый; при отметке строка плавно переезжает в «ЗАБЛОКИРОВАННЫЕ».
4. **Пауза.** Во время блокировки снять приложение → пауза 15 с, как раньше.
5. **Мастер — шапка.** «Пройти настройку заново» → крупно «01 / 07», тонкая полоса; «Далее» — номер растёт, полоса плавно удлиняется; «Назад» — обратно.
6. **Мастер — иконки.** У каждого шага своя иконка (часы, замок, колокольчик, батарея, автозапуск, столбики, галочка).
7. **Мастер — служба.** Карточки «ЧТО ДЕЛАЕТ СЛУЖБА» и «ЧЕГО СЛУЖБА НЕ ДЕЛАЕТ» видны целиком; шаги инструкции с номерами в кружках; статус «✓ Служба работает» бирюзовый.
8. **Мастер — кнопки.** Не сделанный шаг — «Пропустить» в рамке; сделанный — «Далее» терракотовая; последний шаг — «Выбрать приложения» и «На главную».
9. **Sponsr.** На главной «Поблагодарить автора» открывает страницу Sponsr сразу на выборе доната.
10. *(Необязательно)* **Тесты:** → 157 зелёных тестов.
