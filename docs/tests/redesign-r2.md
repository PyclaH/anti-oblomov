# Редизайн R2: Главная — чек-лист проверки

Что изменилось (по макету R0, вариант A):

- **Кольцо-циферблат** вместо цветной карточки статуса: дуга показывает, какая часть идущей блокировки уже прошла; в центре крупно — до какого времени; за кольцом свечение — тёплое при блокировке, холодное в свободное время, янтарное, если служба не работает.
- **«Было / стало»** — заголовок мелкими прописными, справа кнопка списка приложений; три плитки «До / После / Сэкономлено, в день»; строка «Всего ты вернул себе»; подписи и экранное время — по «Подробнее»; веха — отдельной карточкой.
- **«Поблагодарить автора»** — одна строка с логотипом и «Sponsr ›».
- **«Система»** — служба и «Настройка телефона» свёрнуты в строку «Система · всё в порядке». Если что-то не так — строка янтарная, блок раскрыт и стоит сразу под кольцом.
- Для дуги таймера теперь запоминается момент запуска (продление его не сдвигает). Таймеры, запущенные до обновления, начинают дугу с нуля.

Функции не менялись. Перед проверкой: **Git → Fetch** → ветка `origin/redesign-r2` → **Checkout** → **▶ Run**.

## Проверки

1. **Свободное время.** Без таймера и вне интервала: тонкое бирюзовое кольцо без дуги, бирюзовое свечение; «СВОБОДНОЕ ВРЕМЯ», крупно время следующей блокировки и «следующая блокировка» (или «следующая · завтра»); без расписания — «—» и «по расписанию блокировок нет».
2. **Блокировка по расписанию.** Во время интервала: терракотовая дуга от верха по часовой стрелке, длина = прошедшая часть интервала; терракотовое свечение; «ИДЁТ БЛОКИРОВКА», крупно конец интервала, «до конца · по расписанию».
3. **Блокировка по таймеру.** Таймер на 2 мин → на главной дуга растёт примерно на половину за минуту; под временем строка «таймер · осталось 1:23» тикает каждую секунду, цифры не «прыгают». «Продлить» на 2 мин — дуга становится короче (срок вырос), но не начинается заново.
4. **Таймер через полночь.** (Если удобно.) Внизу кольца «завтра · по таймеру».
5. **Служба выключена.** Выключить службу в спецвозможностях → вернуться: свечение и подпись кольца янтарные, под кольцом «Служба блокировки не работает…», сразу под ним раскрытый блок «Система · служба не работает» с кнопкой в настройки. Включить → блок свернулся и уехал вниз, «Система · всё в порядке», точка бирюзовая.
6. **Пропущенная настройка.** «Пройти настройку заново» → пропустить автозапуск (снять «Сделано») → на главной «Система · 1 настройка пропущена» раскрыта под кольцом.
7. **Плитки.** Три плитки одинаковой ширины: «До, в день», «После, в день», «Сэкономлено, в день» (бирюзовая) или «Больше, в день» (терракотовая). Меньше часа — «45 мин», больше — «2:05 ч».
8. **Подробнее.** «Подробнее ›» раскрывает карточку с пояснением «до / после» и экранным временем; «Свернуть» — сворачивает.
9. **Список приложений.** Справа от «БЫЛО / СТАЛО» — «Как в списке блокировки: N ▾» → раскрывается карточка со списком, как на R1 (поиск, «Активировать все»); стрелкой сворачивается, поиск сбрасывается.
10. **Благодарность.** Строка с логотипом «Поблагодарить автора · Sponsr ›», вся строка нажимается и открывает Sponsr.
11. **Без доступа к статистике.** (Необязательно.) Отключить доступ → вместо плиток карточка «Включить доступ».
12. **Прокрутка.** Главная прокручивается до «Системы», капсула меню ничего не перекрывает.
13. *(Необязательно)* **Тесты:** → 157 зелёных тестов.
