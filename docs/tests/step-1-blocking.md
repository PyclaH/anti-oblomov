# Проверка шага 1: пробная блокировка YouTube

**Цель:** понять, надёжно ли служба блокировки работает на Poco (HyperOS), до того как строить на ней всё приложение.

Блокировка включена **всегда** и только для YouTube (расписание и таймер — на следующих шагах).

## Раунд 3 — подготовка

1. **Git → Pull** (ветка `step-1-blocking-spike`), **▶ Run**.
2. Выключить и снова включить «Анти-Обломов: блокировка» в спецвозможностях.
3. Настройки → Приложения → Анти-Обломов: **появился ли «Автозапуск»?** Если да — включить.

## Раунд 3 — проверки

1. **Экран на весь экран.** Открыть YouTube: тёмный фон без полос сверху, снизу и по бокам; логотип не под вырезом камеры, кнопка не под полоской жестов.
2. **Цитаты.** Открыть YouTube 5–6 раз: цитаты разные, длинные (стихи, Козьма Прутков) помещаются целиком.
3. **«Автозапуск».** Появилась ли настройка (подготовка, п. 3).
4. **Смахнуть «Анти-Обломов»** из недавних (без замка) → открыть YouTube → блокируется? Затем открыть «Анти-Обломов» — что пишет карточка?
5. **«Очистить всё»** в недавних → открыть YouTube.
6. **Если 4 или 5 не работают:** закрепить «Анти-Обломов» замком в недавних (потянуть карточку вниз или долгое нажатие → замок) и повторить 4–5.
7. **Перезагрузка** → «Анти-Обломов» не открывать → открыть YouTube.

## Раунд 4 — что изменено

- **Цитаты:** убраны 17 отвлечённых, добавлены 8 мотивирующих к действию, всего 31.
- **«Анти-Обломова» нет в списке недавних** — смахнуть нечего. Открывается только с иконки.
- **Кнопка «Автозапуск (Xiaomi)»** на карточке открывает список автозапуска в приложении «Безопасность»: на HyperOS эта настройка живёт там, а не на странице приложения.

## Раунд 4 — проверки

1. **Git → Pull**, **▶ Run**, выключить и включить службу.
2. **Цитаты.** Открыть YouTube 5–6 раз — нравятся ли новые.
3. **Нет в недавних.** Открыть «Анти-Обломов», выйти на рабочий стол, открыть недавние → его там нет. YouTube блокируется.
4. **«Очистить всё»** в недавних → YouTube блокируется? (Замок теперь поставить некуда.)
5. **Автозапуск.** Нажать «Автозапуск (Xiaomi)» на карточке:
   - что открылось (список автозапуска / страница приложения / ничего);
   - есть ли в списке «Анти-Обломов» → включить.
   - Если кнопка не помогла — вручную: приложение **«Безопасность»** → **Разрешения** (или «Приложения») → **Автозапуск** → «Анти-Обломов».
6. **Перезагрузка** при включённом автозапуске → «Анти-Обломов» не открывать → открыть YouTube.

## Раунд 2 — подготовка (выполнено)

1. В Android Studio: **Git → Pull** (ветка `step-1-blocking-spike`), затем **▶ Run**.
2. На телефоне: Настройки → Приложения → Анти-Обломов:
   - **Автозапуск** — включить;
   - **Контроль активности / Батарея** — «Нет ограничений» (уже сделано в раунде 1).
3. Если служба уже включена — **выключить и снова включить** её в спецвозможностях: в новой версии изменились её настройки, и система может попросить подтверждение заново.

## Раунд 2 — проверки

1. **Статус.** На главной — «Служба работает».
2. **Иконка YouTube** → сразу появляется тёмный экран «YouTube на паузе» с цитатой. «Вернуться к делу» → рабочий стол.
3. **Мини-плеер.**
   1. Выключить службу в спецвозможностях.
   2. Включить любое видео в YouTube и нажать «Домой» — появится мини-плеер.
   3. Включить службу обратно.
   4. Ожидаем: видео в мини-плеере встаёт на паузу.
   5. Развернуть мини-плеер нажатием → должен появиться экран блокировки.
4. **Shorts по ссылке** из Telegram → экран блокировки. Если появился мини-плеер — он на паузе, разворот блокируется.
5. **Другие приложения** (Telegram, браузер, камера) работают как обычно.
6. **Смахнуть «Анти-Обломов»** из недавних → открыть YouTube. Затем открыть «Анти-Обломов» и записать, что пишет карточка.
7. **Перезагрузка** → «Анти-Обломов» не открывать → открыть YouTube.
8. **Долгий фон** (час и больше) → открыть YouTube.
9. **Мелькание:** успевает ли YouTube показаться до экрана блокировки, примерно сколько.

## Если что-то не работает

Пришлите номер проверки и что произошло. Если телефон подключён к компьютеру с Android Studio — строки из **Logcat** с фильтром `AntiOblomov` (выделить → правая кнопка → Copy); это необязательно.

## Для тестов на других телефонах

При установке APK-файлом (не из Android Studio) на Android 13+ система может не дать включить службу: «Ограниченная настройка». Тогда: Настройки → Приложения → Анти-Обломов → ⋮ → **«Разрешить ограниченные настройки»**, затем снова включить службу.
