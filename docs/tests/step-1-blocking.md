# Проверка шага 1: пробная блокировка YouTube

**Цель:** понять, надёжно ли служба блокировки работает на Poco (HyperOS), до того как строить на ней всё приложение.

**Что сделано:** служба спецвозможностей следит, какое приложение открылось. Если это YouTube — отправляет на рабочий стол и показывает экран «YouTube на паузе» с цитатой. Блокировка включена **всегда** (расписание и таймер — на следующих шагах).

## Подготовка

1. В Android Studio: **Git → Fetch**, затем **Git → Branches → Remote → origin/step-1-blocking-spike → Checkout**.
2. **▶ Run** на Poco.
3. Внизу открыть вкладку **Logcat**, в поле фильтра ввести `AntiOblomov` — сюда служба пишет, что видит.

## Проверки

Отмечайте результат в таблице в конце.

1. **Включение службы.** На главной — карточка «Служба выключена». Нажать «Открыть настройки», найти «Анти-Обломов: блокировка», включить, подтвердить предупреждение системы. Вернуться в приложение → карточка «Служба включена».
2. **Блокировка с рабочего стола.** Открыть YouTube с иконки → YouTube закрывается, появляется тёмный экран «YouTube на паузе» с цитатой.
   - Если YouTube закрылся, **но экран с цитатой не появился** — HyperOS запрещает показывать окна из фона. Включить: Настройки → Приложения → Анти-Обломов → Другие разрешения → **«Отображать всплывающие окна, когда приложение работает в фоновом режиме»** → Разрешить. Повторить и записать, помогло ли.
3. **«Вернуться к делу»** → закрывает экран, виден рабочий стол. То же — системной кнопкой/жестом «Назад».
4. **Другие пути в YouTube:** из списка недавних; по ссылке на видео из Telegram или браузера; через поиск по телефону.
5. **Другие приложения не трогаем:** Telegram, браузер, камера открываются как обычно.
6. **Смахнуть «Анти-Обломов»** из списка недавних → открыть YouTube.
7. **Перезагрузка:** перезагрузить телефон, «Анти-Обломов» не открывать, сразу открыть YouTube.
8. **Долгий фон:** заблокировать экран телефона минимум на час (лучше на ночь), потом открыть YouTube.
9. **Скорость (NFR-04):** 5 раз открыть YouTube, в Logcat найти строки `Блокирую com.google.android.youtube, реакция N мс` и выписать числа. Отдельно: успевает ли глазом мелькнуть YouTube.

## Если что-то не работает

Пришлите номер проверки, что произошло, и строки из Logcat с фильтром `AntiOblomov` (выделить → правая кнопка → Copy).

## Примечание для тестов на других телефонах

При установке APK-файлом (не из Android Studio) на Android 13+ система может не дать включить службу: «Ограниченная настройка». Тогда: Настройки → Приложения → Анти-Обломов → ⋮ (вверху справа) → **«Разрешить ограниченные настройки»**, затем снова включить службу.
