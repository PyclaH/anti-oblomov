# Проверка шага 4: экран «Расписание»

**Что сделано** (FR-03…FR-05):

- Кнопки дней **Пн…Вс**; выбранный подсвечен, точка под днём — в этот день есть расписание. При открытии выбран сегодняшний день.
- Интервалы дня списком; между ними — **перерыв** в пунктирной рамке: «14:00–15:00 · перерыв, всё открыто».
- **«+ Интервал»**: новый начинается там, где кончается последний (в пустой день — 09:00–13:00); время — в стандартных часах Android. **Конец 00:00 = до полуночи.**
- Нажатие на интервал — правка; корзина — удаление.
- **Проверка (FR-04):** нельзя сохранить, если конец не позже начала или интервал пересекается с другим — подсказка называет, с каким. Соприкасаться можно (10–14 и 14–15).
- **«Копировать на будни (Пн–Пт)»**: если в буднях уже другое расписание — сначала спросит. Выходные не трогает.
- Сверху — что сейчас: «блокировка до 14:00» или «свободное время · следующая блокировка Пн 10:00»; предупреждение, если не выбрано ни одного приложения.
- Количество интервалов не ограничено.
- На панели проверки на главной кнопка «Расписание: со следующей минуты…» теперь **добавляет** интервал, а не стирает расписание дня; кнопку «Сбросить» убрал — для этого теперь есть экран.

## Подготовка

1. Android Studio: **Git → Fetch** → **Git → Branches → Remote → origin/step-4-schedule → Checkout**.
2. **▶ Run** на Poco. На вкладке «Приложения» отмечен хотя бы YouTube.

## Проверки

1. **Дни.** Вкладка «Расписание» открывается на сегодняшнем дне (подпись «· сегодня»); переключение дней работает.
2. **Добавление.** В пустой день «+ Интервал» → 09:00–13:00 → «Сохранить». Ещё раз «+ Интервал» → предлагает 13:00–14:00. Изменить начало на 15:00, конец на 20:00 → появляется перерыв «13:00–15:00 · перерыв».
3. **Точки.** Под днём с интервалами появилась точка; у пустых дней — нет.
4. **Правка.** Нажать на интервал → поменять время → «Сохранить» → список обновился и отсортирован по времени.
5. **Ошибки.** Добавить интервал, пересекающийся с существующим, → красная подсказка «Пересекается с интервалом …», «Сохранить» неактивна. Конец раньше начала → «Конец должен быть позже начала».
6. **До полуночи.** Интервал 22:00 — конец 00:00 → сохраняется как «22:00–24:00».
7. **Удаление.** Корзина у интервала → исчез; удалить все → «В этот день блокировки нет», точка пропала.
8. **Копирование на будни.** Заполнить понедельник → «Копировать на будни» → у Вт–Пт то же расписание, у Сб–Вс — без изменений. Изменить среду → снова копировать из понедельника → спрашивает «Расписание на среду будет заменено…».
9. **Блокировка по расписанию с экрана.** Добавить на сегодня интервал, который начинается через 1–2 минуты → строка вверху «следующая блокировка ЧЧ:ММ» → в это время YouTube блокируется, после конца — открывается.
10. **Сохранение после перезагрузки.** Расписание на неделю на месте.
11. *(Необязательно)* **Тесты:** `app/src/test/…/rules` → **Run Tests in 'rules'** → 56 зелёных тестов.

## Раунд 2: замечания Руслана (25.10.2026)

Результаты раунда 1: пункты 1–10 — «Работает идеально». Что изменилось:

- время интервала набирается **цифрами с клавиатуры** вместо циферблата;
- пересекающиеся и соприкасающиеся интервалы **молча объединяются** (подсказки «Пересекается…» больше нет);
- если **идёт блокировка**, а правка касается **сегодняшнего расписания** или **списка приложений**, — сначала **15 секунд** паузы с цитатой на фоне-картинке.

Перед проверкой: **Git → Pull**, затем **▶ Run**.

### Проверки

12. **Ввод с клавиатуры.** «+ Интервал» → сразу открывается цифровая клавиатура, время начала выделено. Набрать `0930` → в поле «09:30», курсор сам перешёл в «Конец». Набрать `14` → «14», ниже «Блокировка 09:30–14:00» → «Сохранить».
13. **Короткий ввод.** `930` → 9:30; `9` → 9:00; конец `2400` или `0000` → «…–24:00».
14. **Неверное время.** Начало `2500` или `1275` → красная подсказка, «Сохранить» неактивна. Конец раньше начала → «Конец должен быть позже начала».
15. **Объединение при пересечении.** Есть 10:00–14:00 и 15:00–20:00 → добавить 13:00–16:00 → остаётся один интервал 10:00–20:00, без предупреждений.
16. **Объединение встык.** Есть 10:00–14:00 → добавить 14:00–15:00 → один интервал 10:00–15:00. Интервал внутри другого (11:00–12:00) просто «растворяется».
17. **Пауза — расписание.** Сделать, чтобы блокировка шла сейчас (интервал на сегодня через текущее время). Удалить или изменить сегодняшний интервал → во весь экран цитата с фоном, кнопка «Подтвердить через 15 с» неактивна и считает секунды. «Не менять» → ничего не изменилось. Повторить и дождаться → «Подтвердить» → изменение сохранилось.
18. **Пауза — приложения.** Во время блокировки на вкладке «Приложения» снять или поставить переключатель → та же пауза; «Не менять» → переключатель остался как был.
19. **Без паузы.** Во время блокировки правка **другого** дня — сохраняется сразу. Без блокировки любые правки — сразу.
20. *(Необязательно)* **Тесты:** `app/src/test/…/rules` → **Run Tests in 'rules'** → 75 зелёных тестов.
