# Чек-лист: сайт для скачивания (site/)

Перед проверкой: PR слит, репозиторий публичный, в Settings → Pages выбран источник «GitHub Actions», во вкладке Actions прошёл «Сайт на GitHub Pages». Адрес: https://pyclah.github.io/anti-oblomov/

| # | Что проверить | Ожидаемо |
| --- | --- | --- |
| 1 | Открыть сайт на Android-телефоне | Первая кнопка — «Скачать для Android», под ней «APK · версия 1.2 · 7,1 МБ · Android 8 и новее» |
| 2 | Нажать «Скачать для Android» | Сразу скачивается `anti-oblomov-1.2.apk`, а не открывается страница GitHub |
| 3 | Установить скачанный APK поверх текущего | Ставится как обновление, настройки на месте |
| 4 | Открыть сайт на iPhone | Первая кнопка — «iPhone — скоро», ведёт к блоку про iPhone |
| 5 | Открыть сайт на компьютере | Виден QR-код; камера телефона открывает этот же сайт |
| 6 | Демо: «Идёт блокировка» → «Лента» | Экран с цитатой; в «острове» и на виджете идёт отсчёт |
| 7 | Демо: «Остановить блокировку» | Кольцо 15 с; кнопка «Остановить» оживает только в конце; «Отмена» возвращает домой |
| 8 | Демо: «Свободное время» → «Лента» | Открывается лента с таймером «сколько уже листаешь» |
| 9 | Шаги 01–03 и вопросы внизу | Раскрываются и сворачиваются по нажатию |
| 10 | Ссылки в подвале | Политика, лицензия, все версии, поддержка открываются |
| 11 | Повернуть телефон / узкий экран | Ничего не вылезает за край, нет горизонтальной прокрутки |
