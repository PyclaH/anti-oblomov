# Эксперимент: помогает ли «Анти-Обломов» проводить меньше времени в отвлекающих приложениях

Решения от 26.10.2026: 8–10 участников (одноклассники), 2 недели, итоги — по скриншотам, памятки не нужны.

## Вопрос и что измеряем

**Вопрос:** уменьшается ли время в выбранных отвлекающих приложениях после установки «Анти-Обломова» — и не перетекает ли оно в другие приложения.

**Измеряем** (всё уже считает приложение, вкладка «Главная» → «Было / стало»):

| Что | Где в приложении |
| --- | --- |
| До, в день — среднее время в выбранных приложениях до установки | плитка «До, в день» |
| После, в день — то же после установки | плитка «После, в день» |
| Сэкономлено, в день | третья плитка |
| Сколько дней в «до» и «после» | «Подробнее» — первая строка |
| Всё экранное время до и после, в день | «Подробнее» — две нижние строки |

«До» берётся из истории самого телефона за прошлые недели — данные есть сразу, ждать не нужно. Последние строки (всё экранное время) показывают, не ушло ли время просто в другие приложения: это честная проверка, её обязательно показываем на защите.

## Порядок

1. **День 0 — установка** по [инструкции и чек-листу](tests/step-8-devices.md). Участник получает код У1…У10.
2. **Не менять список приложений для статистики** — оставить «Как в списке блокировки» (по умолчанию), чтобы у всех считалось одинаково. Список блокировки можно менять, но лучше в первый день и больше не трогать.
3. **День 7** — скриншот 1: Главная, «Было / стало» с раскрытым «Подробнее» (плитки + строки ниже на одном или двух скриншотах).
4. **День 14** — скриншот 2 — то же самое. С 14-го дня появится карточка вехи «2 недели» — её тоже в скриншот.
5. Скриншоты присылать Руслану; имя файла: `У3_день14.png`.

| --- | --- | --- | --- | --- | --- | --- | --- |
| У1 | | | | | | | |
| … | | | | | | | |

Разница = До − После (плюс — время сократилось).

## Как подводить итог — честно

Участников мало (8–10), поэтому никаких «в среднем на 47,3 % меньше» с точностью до десятых. Показываем:

- **Каждого участника** — столбики «до» и «после» рядом (график по таблице сделаю).
- **Медиану** разницы и **разброс** (от минимальной до максимальной), а не только среднее: один участник с огромной разницей не должен «тащить» итог.
- **Сколько участников из всех сократили время** — например, «у 8 из 10». Если сократили почти все, это уже заметный результат: при 9 из 10 вероятность получить такое случайно (как если бы приложение не влияло и каждый мог с равным шансом пойти в плюс или минус) — около 2 % (знаковый критерий).
- **Всё экранное время** до и после — сократилось ли оно тоже или время ушло в другие приложения.

## Ограничения — сказать на защите вслух

- **Нет контрольной группы.** Сравниваем «до» и «после» у тех же людей; на время в телефоне влияют и другие вещи (контрольные, погода, каникулы).
- **Каникулы.** Если «до» или «после» попадает на осенние каникулы, сравнение искажается — в каникулы времени в телефоне обычно больше. **Проверить даты каникул в гимназии и начать так, чтобы 2 недели «после» были учебными**, или прямо оговорить это в выводах.
- **Эффект новизны.** Первые дни с новым приложением люди стараются больше; 2 недели — минимум, чтобы он начал проходить.
- **Добровольцы.** Участвуют те, кто сам хочет меньше сидеть в телефоне, — у них результат может быть лучше, чем был бы у всех.
- **Разная длина «до».** У кого-то история телефона за 2 недели, у кого-то за 2 месяца — это видно в «Подробнее», записываем в таблицу.
