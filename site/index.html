Как начать?

01

Скачай APK

Нажми «Скачать для Android» на телефоне и открой скачанный файл.

Если открываешь сайт на компьютере — отсканируй QR-код камерой телефона.

Подробнее +
02

Разреши установку

Телефон спросит, можно ли ставить приложения из браузера, — разреши.

Если Play Защита предупредит о неизвестном разработчике: «Подробнее» → «Всё равно установить». Так бывает со всеми приложениями не из магазина.

Подробнее +
03

Пройди мастер

Приложение само проведёт по настройкам твоего телефона — Xiaomi, Samsung и других.

Android 13+ может написать «Ограниченная настройка» на шаге службы блокировки. Решение: Настройки → Приложения → Анти-Обломов → ⋮ → «Разрешить ограниченные настройки». Мастер подскажет.

для Android

Apple разрешает ставить приложения только через App Store и TestFlight, а блокировать другие приложения — только через «Экранное время» с отдельного разрешения Apple. Поэтому скачать файл для iPhone, как для Android, нельзя, а версия для iPhone — отдельный большой проект. Мы вернёмся к нему позже и обязательно расскажем, если он начнётся.
